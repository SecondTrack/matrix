# Matrix

**Chat over Matrix**

A real Matrix client: sign in at matrix.org or your own server, open rooms, write messages. Encrypted rooms will follow.

## Features

- Sign in at matrix.org or your own server
- Rooms and direct messages
- Send and receive messages in real time

## Runs on

iOS 6.1.6 · jailbroken iPod touch

## Install

The easiest way is the **[Reboot App Store](https://github.com/SecondTrack/reboot)** right on the iPod.
By hand: download the `.deb` from the [latest release](https://github.com/SecondTrack/matrix/releases/latest), install it with `dpkg -i`, then run `uicache`.

## Build it yourself

With [Theos](https://theos.dev) (iOS SDK with armv7):

```sh
make package
```
